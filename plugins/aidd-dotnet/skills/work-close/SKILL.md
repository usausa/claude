# 作業のクローズ(片付けて終える)

> メインは片付け: 最終プッシュ・ブランチ削除・作業フォルダ削除。**蒸留は例外処理** — 決定や用語は発生した時点で ADR / rules / glossary に落ちているのが正常で、ここで見つかるのは漏れ。

## 手順

1. **蒸留漏れの確認(通常は空振り)**: 作業フォルダ(解決規則は `work-init` skill)の一時物(lite = SPEC / PLAN、full = PLAN。SDD レベルは `.claude/rules/aidd.md`)を読み、恒久化されずに消える内容がないか確認する:
   - 決定と理由 → `docs/adr/`(漏れがあれば**削除前に人へ確認**し、ADR の枠を用意する)
   - 用語 → `docs/glossary.md` / 受け入れ条件 → **テスト名**(漏れがあればテストを足す)
   - 実装詳細・手順・チェックリストはコードと git 履歴で分かるため対象外。
2. PLAN のチェックリストが全て `- [x]` であることを確認する(残があれば未完了 = 閉じない)。
3. 作業フォルダの一時物(ブランチフォルダ方式ならフォルダごと)を削除する。**full では SPEC は削除しない** — `spec-close` の手順で蒸留して `docs/spec/` に残す(status 更新)。
4. **最終コミット・プッシュ**: `git-commit` skill の規約で、削除を含む最終コミット → push を行う(このスキルとして依頼された場合は AI が実行してよい。push 等は permission の確認が入る)。
5. **ブランチ削除**: マージ完了後にブランチを削除する(`git branch -d <branch>`、リモートは `git push origin --delete <branch>`。マージ前は実行しない)。
6. **孤児検出**: 他にマージ済みブランチの `docs/work/*/` が残っていれば報告する。
