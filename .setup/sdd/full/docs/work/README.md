# work(一時プラン置き場)

> ここは**一時物**の置き場(git 管理。完了時に削除するが履歴には残る)。PLAN は恒久文書化せず、機能の完了時に削除する(仕様は `docs/spec/` の恒久文書)。

## 作業フォルダの解決規則(中間フローが共有する正)

1. `docs/work/<現ブランチの slug>/` が存在する → それを使う(slug = ブランチ名の `/` を `-` に置換)
2. 存在しない → `docs/work/` 直下(従来形式)

- ブランチフォルダ方式: `PLAN.md` / 直下方式: `PLAN-<topic>.md`
- 初期化(`work-init`)と完了(`work-close`)は**任意**。中間フローはこの規則だけに依存し、どちらの方式でも動く。
